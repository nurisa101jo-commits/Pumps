# Projects and Selection Sheets

A project is the commercial/engineering workspace for one customer requirement.

A project can contain multiple duty points. The user selects one valid pump configuration and the selected component options are stored with the project.

The final Selection Sheet is generated from:
- project/customer information
- selected configuration
- compatible component options
- dimensions and product information
- structured performance curves
- project duty points
- engineering warnings

The same project data is later used to generate the printable PDF and quotation-ready selection document.
