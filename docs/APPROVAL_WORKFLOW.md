# AI Approval Workflow

1. Import document/image/spreadsheet.
2. AI extracts candidate product data and source references.
3. System detects conflicts and inconsistencies.
4. Engineer edits any extracted values.
5. Engineer reviews conflicts; conflicts do not automatically block approval.
6. If conflicts remain, Approve requires explicit second confirmation.
7. Approved data becomes production catalog data.
8. Every approval/change is written to the audit trail.

AI has no direct production-publish operation.
