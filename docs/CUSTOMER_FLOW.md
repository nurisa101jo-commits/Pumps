# Customer Selection Flow

The customer never selects an arbitrary motor, flange, impeller, or other component.

1. Select a pump series/model.
2. The platform loads only configurations that are valid for that pump.
3. The customer sees compatible motors, flanges, impellers, seals, materials and accessories.
4. The hydraulic duty point is evaluated against the selected configuration's structured curves.
5. The final configuration produces a Selection Sheet containing the product image, product code, selected components, dimensions, curve with duty point, duty data, application information, and general product information.
6. The user can review/edit the configuration, save the project, generate a PDF and print.

Component compatibility is determined by company product data and engineering rules, not by free-form customer selection.
